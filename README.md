# A Little Birthday Adventure

A small, static birthday puzzle gift. Open `index.html` locally or publish this folder with GitHub Pages.

## Publish with GitHub Pages

1. Create a new public GitHub repository (for example `birthday-surprise`).
2. Add `index.html`, `birthday-art.jpg`, and this README at the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to finish publishing. Its URL appears in the Pages settings. Open that URL on a phone to check it before sharing.

The birthday illustration is bundled locally and remains the original uploaded image. No service or login is required to play. No backend is configured for wishes. “Keep it just for me” sends and stores nothing. “Share my wish with you two” saves the wish with a timestamp in this browser's local storage only; it is not sent to a server, so the birthday girl can choose to show it to her friends in person. Browser storage may be cleared by the device/browser.

To edit the final birthday message, change the text inside the `#final` section in `index.html`.
